# Hyprland Config - v2

This repository contains my personal Hyprland configuration.

## What's New in v2 (Dark Theme Update)

The second iteration of this configuration focuses on transitioning to a cohesive dark blue aesthetic and fixing hardware-level display issues with Nvidia graphics cards.

### 🌟 Key Changes & Improvements

1. **Dark Blue Aesthetic Overhaul**
   - Completely transitioned the color palette to deep blue and dark tones, moving away from the default light theme.
   - Updated the primary wallpaper to a matching dark blue aesthetic via `hyprpaper`.
   - Adjusted window border colors to match the new dark blue color scheme for both active and inactive states.

2. **Nvidia Hardware Cursor Fix**
   - Added specific environment variables (`WLR_NO_HARDWARE_CURSORS`) to fix the invisible cursor bug when running under proprietary Nvidia drivers on Wayland.
